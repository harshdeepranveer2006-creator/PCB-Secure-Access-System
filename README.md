# PCB Secure Access System

## Overview

PCB Secure Access System is a password-based access control project developed using an Arduino Nano and a custom Zero PCB.

The system uses LED indicators and a piezo buzzer to provide user feedback during authentication. A Python-based dashboard application was also developed for monitoring and interaction with the system.

The project demonstrates PCB design, embedded programming, hardware assembly, soldering, and desktop software development.

## Features

- Password-based authentication
- Arduino Nano firmware
- Custom PCB design
- Python desktop dashboard
- Secure access control
- Embedded systems implementation
